## Change

| Part | Before | After |
| --- | --- | --- |
| Logged path | cut at the first `?`, `;`, `%3F` or `%3B`; a raw `#` or `%23` and what follows were logged | also cut at `#` and `%23`, the same rule as the `Referer` (the optional item, fixed) |
| Smoke test | 4 states, 6 sensitive request kinds | adds the cases below; each case carries its own markers, so a failure names the case |
| Stub backend | answers `200` everywhere | also closes the connection without an answer (`444`) on `/api/upstream-close` |
| README, edge logs | rotation as a list of what to rotate | rotation as six steps; the rule for a proxy, tunnel or load balancer in front of the edge; the Vite dev server note |

A browser never sends a fragment, so the `#` cut changes no line a real client produces; it makes the path and `Referer` rules agree.

## Checks

All cases run in `scripts/tests/nginx-log-redaction-smoke.sh`, which the `nginx-headers` job of `.github/workflows/frontend.yml` runs. Each one checks that neither output stream holds its markers and that no request scoped error line is written. Requests curl cannot send (a malformed line, an absolute form target, a raw `#`) go through bash's `/dev/tcp`, a builtin, so no marker reaches an argument list.

## Limitations

- The `429` count depends on how fast the runner delivers the burst; the test asks for at least one refusal, and `nginx-login-rate-limit-smoke.sh` checks the exact counts.
- A `Referer` cannot carry a raw line break: curl and nginx both refuse one in a header, so the one line check covers the quote and backslash escape only.
- Only the shipped edge is covered. An outer proxy, tunnel or load balancer, or a deployment that mounts another nginx configuration, must follow the same rule; this test cannot see those logs.
- The Vite check was one manual probe on one version; a later Vite may log differently.

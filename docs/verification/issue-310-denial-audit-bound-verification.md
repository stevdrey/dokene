## Call sites that can reach the shared slot

Read from the code, not proven exhaustively. The shared slot is charged only when no tenant context is bound and no identity is passed.

- `TenantContextRequestFilter`: passes the resolved identity. It passes none only for an authenticated principal that is not an `AuthenticatedTenantIdentity`, which the OIDC login never produces.
- `TenantController.getWorkspace` and `WorkspaceProvisioningService`: always pass the identity.
- `DurableAuthorizationAuditListener`, `DurableAiActionGateAuditListener`, `DurableIntegrationAuditAdapter`, `DurableTemplateAuditAdapter`: use the two argument form. On every tenant scoped route the filter has bound a context or already refused the request, so these charge the context identity. They reach the shared slot only when enforcement runs with no context, which no HTTP route was found to allow: the global routes (`/api/tenants/**`, `/api/session`) do not call permission enforcement.

No route was found where a user can cause denials with no identity at will.

## Changes to existing tests

Spec 0020 says the existing denial tests pass unchanged. Four existing test files had to change, none in what it asserts about a refusal:

- `TenantContextRequestFilterTest` (7 lines) and `TenantControllerTest` (1 line) verify the recorder call on a mock, and now expect the identity as the third argument.
- `AuditIntegrationTest` names the signature of `dokene.append_audit_event` in a `REVOKE` and `GRANT`; it now names the V40 signature.
- `TenantPersistenceIntegrationTest` pins the current schema version, now 40.
- The two `TransactionalAuditRecorder` unit tests pass the two new constructor arguments.

## Residual risk

As listed in ADR 0032: state per instance, counts lost on a hard stop or past the shutdown deadline, a full tracker that takes about 100 minutes to empty, one table scan under an exclusive lock in V40 (not measured on a large table), a ceiling shared across an identity's tenants, counting without rows while the tracker is full, one shared slot for denials with no identity, and no retention on `audit_events`.
